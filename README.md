# 刘鹏熙 · Personal Portfolio

基于所提供 GZ.STORE 模板的视觉语言重新制作的个人网站：荧光绿、紫色、粗边框、硬阴影、倾斜拼贴。使用 React、TypeScript 和 Vite，当前为前端版本，尚未接入后端。

## 本地启动

需要 Node.js 20+。在本目录运行：

```sh
npm install
npm run dev
```

也可以双击 `start-local.cmd`。以终端打印的地址为准，默认 http://127.0.0.1:5173/ 。关闭终端会停止服务。

```sh
npm run build
npm run preview
```

构建结果为 `dist/`。开发服务器和预览服务器仅绑定本机，不会对局域网公开。

## 当前功能

- 桌面、平板及手机响应式布局
- 项目分类筛选、详情弹窗、Escape 关闭及键盘焦点限制
- 关于我、教育、实习与校园经历、奖项
- 简历下载、邮件联系、复制邮箱
- 移动导航、锚点跳转、减少动画偏好适配
- 字体和头像均在本地，不依赖外部字体服务

## 内容修改

- `src/data/portfolio.ts`：个人信息、项目内容与头像路径
- `src/App.tsx`：页面结构及交互
- `src/styles.css`：色彩、排版与响应式样式
- `public/assets/`：头像和原始简历
- `reference/`：压缩包原始源码，仅用于视觉参考，已被 Git 忽略

## 后续接后端

目前 `portfolio.ts` 是内容数据入口，前端无需后端即可运行。后续根据实际需求接入：

1. `GET /api/projects`：返回 `Project[]`，替换静态数据来源。
2. 内容管理：项目、作品图片、经历的增删改查，配套管理员鉴权。
3. 联系表单：有明确需要时新增服务端验证、防刷及邮件发送；目前联系入口直接打开邮件客户端，不会假装提交成功。

不在浏览器源码中放置模型 API Key 或邮件凭据。

## 上传 GitHub

仓库包含网站源码、使用中的头像、可下载简历、`package.json` 和 `package-lock.json`。`node_modules/`、构建产物、参考模板、测试截图和未选用的头像已通过 `.gitignore` 排除。

如使用 GitHub Pages，可通过 Actions 执行 `npm ci`、`npm run build` 后发布 `dist/`。Vite 已使用相对资源路径以兼容仓库子目录；这个版本没有服务端功能，适合静态托管。未来接后端时需另选可运行 API 的环境。
